# Suivi de finance

Le fichier `Suivi de Finance.xlsx` vit ici pour tenir les comptes plus simplement,
mais il **n'est pas versionné** (voir `.gitignore` : le dépôt est public).

La version de référence est celle du **Google Drive de NovaFlows**. Après chaque
modification du fichier ici, il faut **remettre la nouvelle version sur le Drive**
(remplacer l'ancienne), sinon les deux copies divergent.
