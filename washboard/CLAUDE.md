## Présentation publique de réservation
- `washers.booking_page_mode` : `default` pour le parcours compact, `custom` pour la présentation classique personnalisable. Colonne en base depuis le 2026-10-03 (migration appliquée directement via l'API Management Supabase, pas de fichier dans `supabase/migrations/` — convention du projet : SQL donné en direct, jamais commité).
- **La bascule reste limitée à deux comptes de test** (`COMPTES_TEST_NOUVELLE_PAGE_RESERVATION` dans `lib/bookingPageMode.ts` : `test-config-15d2`, `autonettoyage`) via `bookingPageModeEffectif(slug, value)`. Tout autre compte reste sur la page classique quoi que vaille la colonne — la ligne 6 ci-dessus décrit le COMPORTEMENT des deux comptes de test, pas celui de tous les laveurs. Ajoutée le 2026-10-03 après avoir repéré que `default` écrasait silencieusement la couleur de marque et le fond personnalisé de comptes payants réels.
- Un interrupteur (pas une case à cocher) « Page par défaut » : actif = default, inactif = custom avec les réglages visibles. Commun à `IdentiteForm` (web) et `ApparenceV2` (PWA), via `BookingPageModePicker` et PATCH /api/washer. Changer le mode ne supprime jamais les réglages d'apparence. Logo et Couleur restent modifiables quel que soit le mode (depuis le 2026-10-04) ; Fond et Message d'accueil restent réservés au mode custom, la nouvelle page ne s'en sert pas encore.
- La route `/book/[slug]` charge et contrôle les données une seule fois, puis rend `BookingForm` ou `LegacyBookingPage`. Garder les listes explicites des champs envoyés aux composants clients.
- `e2e/booking-refonte.spec.ts` (Playwright, config `playwright.refonte.config.ts`) : seul test de bout en bout sur ce parcours, sur données fictives (`/dev/booking-preview`, slug de démo `test-config-15d2` — doit rester dans `COMPTES_TEST_NOUVELLE_PAGE_RESERVATION` pour que le sélecteur de page s'affiche dans la démo). À rejouer après toute modification de `BookingPageModePicker`, `IdentiteForm` ou `ApparenceV2` : deux régressions silencieuses (rôle ARIA du contrôle, slug hors liste) y sont passées inaperçues jusqu'au 2026-10-04, faute d'avoir été rejoué.
