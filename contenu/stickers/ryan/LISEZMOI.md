# Stickers de Ryan

Mets ici tes stickers détourés (PNG à fond transparent, environ 700 px de large, personnage en entier sans marge inutile),
nommés comme ceux d'Alexandre pour que les modèles marchent tels quels : `p05.png` = tu réfléchis, `p09.png` = pouce levé, etc.
La liste des poses est dans `../poses.json` (et la planche d'Alexandre dans `../alexandre/`).

Les plus utilisées dans les posts : p05, p09, p12, p14, p18, p06, p08, p02, p07, p28. Commence par celles-là.

Pour alléger un PNG : `python ../../outils/alleger-stickers.py ryan`.
